# LED Distance Detector Without a Microcontroller

An ultrasonic distance-detection circuit built using a **555 timer IC and basic electronic components**, providing visual and audible alerts when an object approaches the sensor. The project demonstrates a practical sensing system without relying on a programmable microcontroller.

## 🔍 Project Overview

This project implements an LED-based distance detector using an ultrasonic sensor, a 555 timer IC, and discrete electronic components. The circuit detects nearby objects and activates an LED and buzzer to provide visual and audible feedback.

The main objective was to explore ultrasonic sensing, timer-based signal processing, and electronic circuit design without using a microcontroller.

## ⚙️ Components Used

- Ultrasonic sensor
- 555 timer IC
- LED
- Buzzer
- Resistors: 1 kΩ and 470 Ω
- Polarized capacitor(s)
- 3.5 V lithium battery

**Key feature:** The circuit uses a 555 timer IC and electronic components rather than a programmable microcontroller such as an Arduino or ESP32.

## 🛠️ Working Principle

1. The ultrasonic sensor transmits ultrasonic waves toward nearby objects.
2. Reflected waves are received by the sensor.
3. The detection signal is processed by the circuit involving the 555 timer IC.
4. When an object is detected within the circuit's operating range, the LED and buzzer provide an alert.
5. When no qualifying detection occurs, the indicators remain inactive.
